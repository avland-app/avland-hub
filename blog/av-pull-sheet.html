What an AV pull sheet is and how to make one

November 6, 2026 · 5 min read

An AV pull sheet is the checklist your shop uses to pull, check and load every piece of gear for a job. It lists each item with a quantity, where it lives in the warehouse and which case or truck it goes in, so the crew isn't working from memory the night before load-out. A good one is built from the approved quote, not from a text thread.

Below is what goes on a pull sheet, how it differs from a quote, how to build one that survives a busy prep day, and the checks that keep a forgotten cable from becoming a show-day problem.

What a pull sheet is, and how it differs from a quote

The quote is for the client. It shows what they're paying for, grouped so a non-technical person can approve it. The pull sheet is for your own crew. It shows what has to physically leave the building.

That difference changes what goes on the page. A quote might say "Wireless microphone package, 4." A pull sheet has to say four handhelds, four receivers, antennas, a distro, spare batteries, and the case they travel in. The client never needs that detail. The person loading the truck does.

What to put on every line

Keep the columns the same on every job so the crew learns where to look:

  • Item and quantity. Use the same names as your inventory, so a count matches what's on the shelf.
  • Location or case. Rack, shelf, road case or bin. This is what makes pulling fast.
  • Included parts. For kits, list what's inside: power cables, adapters, clips, remotes.
  • Source. Owned, sub-rented from a vendor, or supplied by the client. Gear you don't own needs a pickup and a return.
  • Check boxes. One for pulled, one for tested, one for loaded, and one for returned after the show.
  • Notes. Firmware, special cables, anything the venue asked for.

Build it from the approved quote

The most common cause of a bad pull sheet is that it was typed separately from the quote. The client adds a second confidence monitor on Tuesday, the quote gets a new revision, and the pull sheet still shows the old list.

The fix is a single rule: the pull sheet is generated from the latest approved version of the quote, and nobody edits gear on it by hand. If the gear changes, the quote changes, and the pull sheet follows. Our guide to writing an AV quote clients approve covers how to structure the quote so this works.

Pull, test, then load

Pulling gear off the shelf only proves it exists. Testing it proves it works. Put both steps on the sheet, in that order, and have a different person do the load check when you can.

AVIXA's hybrid event production guide makes the same point for live events. It advises that you perform end-to-end tests with all equipment and platforms in the environment where they'll be used, and keep replacement mics, cables and batteries within reach to swap out faulty hardware. Both belong on your sheet: a test column for the first, and a spares section for the second.

The spares section most sheets leave out

Spares are the first thing cut when a truck gets tight, and the first thing wanted on site. List them as their own block so they get pulled on purpose:

  • Batteries and chargers for every wireless system.
  • Extra cables of each type, in the lengths you actually use.
  • Adapters and gender changers for common connections.
  • Gaff tape, labels and cable ties.
  • A spare for anything that has no backup on the job and would stop the show.

Load-out and return: close the loop

A pull sheet isn't finished at load-in. After the show, use the same sheet to check everything back in. Counting gear on return is how you catch the missing adapter while the venue can still look for it, and how you find damaged gear before it goes out on the next job.

It also tells you what to flag for repair, which feeds back into your next quote.

Common mistakes

  • Working from the quote's wording. Quote language is written for the client, not for pulling.
  • No location column. The gear exists, but nobody can find it fast.
  • Kits without contents. "Mic kit" tells a new crew member nothing.
  • Sub-rentals mixed in with owned gear. Someone has to pick them up, and someone has to return them.
  • No return check. Losses show up weeks later, when no one can say where they happened.

Questions

What is an AV pull sheet?

A pull sheet is a checklist of every item to pull from the warehouse, test and load for a job, with quantities, locations and case assignments. It's the crew's version of the quote.

What's the difference between a pull sheet and a pack list?

The terms overlap, and shops use them differently. Many use "pull sheet" for the list of gear to take from the shelf, and "pack list" or "load list" for what goes in each case or truck. Pick one meaning and stay consistent.

Should a pull sheet include spares?

Yes. List batteries, cables, adapters and consumables as their own section so they're pulled on purpose, not if there's room.

Who should make the pull sheet?

Whoever owns the quote should generate it from the approved version. Building it separately is what lets the two drift apart.
